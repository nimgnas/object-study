# 영화 예매 도메인

### 도메인이란?

- 사용자가 프로그램을 사용하는 주제 영역
- 사용자가 프로그램을 사용해서 해결하고 싶은 문제들의 집합
- 소프트웨어로 구현할 요구사항의 범위

### 영화를 예시로 도메인 개념 설명

- **영화** : 영화제목, 러닝타임, 감독, 가격 과 같은 영화를 떠올릴 때 일반적인 정보
- **상영** : 실제로 사용자들이 관람할 수 있도록 특정한 시간에 영화를 공개하는 활동
- **예매** : 사용자가 상영을 구매하면 생성되는 것, 영화의 제목과 상영시간, 예매 인원, 영화의 정가, 결제 금액등의 정보
- **할인 정책** : 할인 정책과, 할인 조건의 조합으로 구현된다.
  - 할인 정책 : 사용자의 예매요금에서 차감할 할인금액을 계산하는 방법
    - 금액 할인 정책 : 항상 동일한 금액을 할인해주는 방식
    - 비율 할인 정책 : 영화의 정가에서 일정한 비율을 할인해주는 방식
  - 할인 조건 : 요금을 할인받기 위해 만족해야 하는 조건
    - 순서 조건 : 상영의 회차를 기준으로 할인 여부 판단
      - 조조 상영인 경우
      - 10회 상영인 경우
    - 기간 조건 : 상영의 시작 시간을 기준으로 할인 여부를 판단
      - 월요일 특정 시간, 목요일 특정 시간
- **다중성** : 도메인 개념들 사이에 연결 가능한 숫자의 범위
